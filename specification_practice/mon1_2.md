# 仕様理解・計画シート：簡易メモ検索機能の開発

## 0. 問題文（要件確認）
- **課題タイトル：** 簡易メモ検索機能のコマンドラインツール開発
- **背景・目的：** 
  社内の開発メンバーが、日々のちょっとしたメモ（テキストファイル）の中から、特定のキーワードを含むメモを手早く探し出せるようにしたい。まずはPythonの標準機能だけで動く、シンプルなコマンドライン用の「メモ検索スクリプト」を開発する。
- **要件：**
  1. **入力：** 検索対象のテキストファイル（`notes.txt` など、1行1件）、コマンドラインで指定する「検索キーワード」
  2. **処理：** ファイルを開き、各行を読み込んでキーワードの有無を判定し、該当行の番号と内容を抽出する
  3. **出力：** 該当行の番号と内容をリスト表示（見つからない場合は「該当するメモはありませんでした。」と表示）
  4. **前提・制約：** Python 3使用、外部ライブラリ不使用、期日は3日後（2026年11月20日）18:00までにGitHubへプッシュ
